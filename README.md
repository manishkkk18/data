# India from data

Maps that turn free satellite data into stories about India.

- `apps/home`: the landing page, served at https://manishkkk18.github.io/data/india/
- `apps/night-lights`: India Night Lights, at /data/india/night-lights/
- `apps/smoke-watch`: India Smoke Watch, at /data/india/smoke-watch/
- `apps/monsoon`: The Monsoon, District by District, at /data/india/monsoon/ (static, no build step; see its README)
